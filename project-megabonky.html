Game Project

Megabonky

Unreal Engine으로 제작한 게임 프로젝트입니다. GAS 기반 전투 시스템, Dedicated Server 구조, 데이터 기반 밸런싱, MCP 기반 에디터 자동화 개선을 중심으로 구현했습니다.

1인 개발 2025.12 - 2026.02 Unreal Engine GAS Dedicated Server

프로젝트 개요

전투, 성장, 네트워크 플레이를 포함한 Unreal Engine 게임 시스템을 직접 설계했습니다. 핵심 로직은 서버 권한을 기준으로 구현하고, 클라이언트는 UI와 입력 흐름을 명확히 분리했습니다.

주요 구현

  • GAS 전투 시스템
    타이머 기반 자동 능력 발동, GameplayEffect, ExecutionCalculation을 활용해 데미지와 능력치를 계산했습니다.
  • Dedicated Server
    게임 서버와 웹 서버의 책임을 분리하고, DB 접근은 웹 서버 API를 통해 처리하도록 구성했습니다.
  • 데이터 기반 밸런싱
    DataTable과 CurveTable로 몬스터 스탯, 스폰 수, 무기 강화 옵션을 관리했습니다.
  • MCP 기반 에디터 자동화
    Unreal MCP 플러그인의 클래스 탐색과 Blueprint 생성 흐름을 개선해 반복 작업을 줄였습니다.

구현 화면

AI 자동화 개선

Unreal MCP 플러그인이 엔진 기본 클래스만 탐색하던 문제를 분석하고, 사용자 정의 C++ 클래스와 Blueprint 클래스를 UClass 로드 경로에서 찾을 수 있도록 개선했습니다. 이를 통해 자연어 명령으로 Blueprint 작성과 컴포넌트 부착을 더 안정적으로 수행할 수 있게 했습니다.
