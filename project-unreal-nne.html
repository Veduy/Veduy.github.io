Unreal NNE

Unreal Engine의 NNE(Neural Network Engine) 플러그인을 사용해 사전 학습된 AI 모델을 엔진에 삽입하고, Blueprint에서 추론 함수를 호출해 결과를 확인하는 실험 프로젝트입니다.

Unreal Engine NNE MNIST Blueprint

프로젝트 개요

미리 학습된 MNIST 모델을 Unreal Engine 내부에서 실행하고, 입력 데이터의 형태 지정부터 추론 결과 처리까지 엔진 환경에서 필요한 흐름을 검증했습니다.

주요 구현

  • 입력 데이터 구성
    28x28 버튼 입력을 float 배열로 변환해 모델 입력 형식에 맞게 전달했습니다.
  • NNE 추론 호출
    C++ 추론 함수를 Blueprint에서 호출할 수 있도록 연결했습니다.
  • 결과 처리
    모델 출력값을 후처리해 사용자가 입력한 숫자 예측 결과를 확인할 수 있게 구성했습니다.
