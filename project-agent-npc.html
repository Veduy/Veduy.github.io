Toy project

Agent NPC

MCP 구조와 AI Agent에 영감을 받아 생성형 AI와 유니티엔진을 활용하여, 간단한 자연어 명령을 처리하는 NPC를 목표로 진행한 프로젝트입니다.

Unity FastAPI Langchain

프로젝트 개요

  • LLM을 활용한 자연어 해석
    사용자의 자연어 입력을 Unity에서 실행 가능한 명령으로 변환하기 위해 `TypedDict` 기반 스키마를 정의하고, LLM 응답을 자유 텍스트가 아닌 명령과 대상 오브젝트 정보를 일관된 구조로 반환하도록 설계했습니다.
  • Tool 기반 행동 계획 에이전트
    Unity 씬 상태 조회 도구를 LLM Agent에게 제공하고, Agent가 필요한 도구를 호출해 현재 상황을 파악한 뒤 실행 가능한 NPC 행동 계획을 생성하도록 구성했습니다.

명령 처리 구조

개발시 겪은 문제

  • 자연어의 의도 판별 라우팅단계 추가
    • OpenAI API를 사용해서 LLM API를 사용해 테스트 하던중, 모든 자연어 입력에 대해서 긴 명령 파싱 프롬프트를 사용하다 보니, 불필요한 토큰 사용량이 증가됨을 확인했습니다. 개선하기위해 상대적으로 API 비용이 낮은 모델로 우선적으로 변경을 하였습니다.
