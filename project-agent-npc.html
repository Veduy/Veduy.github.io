AI NPC Prototype

Agent NPC

AI agent에서 영감을 받아 자연어 명령을 해석해, npc가 행동하도록 구성해본 토이프로젝트입니다.

Unity FastAPI AI Langchain

프로젝트 개요

Agent NPC는 게임 안의 NPC가 자연어 명령을 이해하고, Unity 런타임의 실제 월드 상태를 참고해 이동, 아이템 획득, 아이템 내려놓기 같은 행동을 수행하도록 만드는 토이 프로젝트입니다. 백엔드는 명령 의도를 분류하고 해석하여 구조화된 command JSON을 생성하며, Unity는 벡엔드의 AI Agent가 실행할수 있는 도구들을 제공하고 명령 리스트의 최종 행동 실행을 담당합니다. 벡엔드의 Agent는 제공된 도구를 통해 자연어 명령을, npc가 수행가능한 action 리스트로 생성합니다.

구현 목표

  • 자연어 명령 해석
    FastAPI 백엔드에서 일반 대화, 기능 질문, 즉시 실행 명령, 목표형 명령을 구분하고 실행 가능한 명령만 구조화된 행동으로 변환합니다.
  • Unity 런타임 상태 조회
    백엔드가 WebSocket을 통해 Unity에 `find_object`, `get_agent_state`, `get_inventory` 같은 허용된 함수 실행을 요청하고, 그 결과를 반영해 최종 행동 대상을 결정합니다.
  • NPC 행동 큐 실행
    Unity 쪽에서는 `MOVE_TO`, `GET_ITEM`, `PUT_ITEM`, 등 명령 리스트를 받아 NPC가 명령을 수행합니다.

구조

1 User Command

사용자가 자연어로 NPC에게 명령합니다.

2 FastAPI Backend

OpenAI 구조화 응답과 라우팅으로 실행 가능한 명령을 만듭니다.

3 Unity Runtime

현재 씬 오브젝트와 NPC 상태를 조회하고 행동 큐를 실행합니다.
