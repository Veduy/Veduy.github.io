About Me

최근 가장 몰입감 있게 플레이한 게임은 Dragon's Dogma II입니다.

이 게임에서 강한 몰입을 느낄 수 있었던 이유는 오픈 월드 속 다양한 이벤트와 스토리도 있었지만, 무엇보다 AI 폰과 협력하는 전투 경험 때문이었습니다.

전투 중 AI 캐릭터들은 단순히 미리 짜인 코드에 따라 움직이는 존재가 아니라, 상황을 판단하고 의사결정을 내리는 '생각하는 동료'처럼 느껴졌습니다. 그로 인해 플레이어 캐릭터에 더욱 깊이 몰입할 수 있었고, 게임 세계가 한층 살아 있는 공간처럼 다가왔습니다.

게임 개발자로서 저는 이러한 몰입감을 만들어내는 게임을 직접 구현하고 싶습니다. AI 기술이 빠르게 발전하며 예측하기 어려운 단계로 나아가는 지금, 게임 속 캐릭터들이 진정한 의미의 AI로서 기능하는 시대 역시 머지않아 도래할 것이라 생각합니다.

그 변화의 순간에, 단순히 따라가는 개발자가 아닌 그 흐름을 이끄는 개발자가 되는 것이 저의 목표입니다.

Technical Implementation

서버 아키텍처 및 통신

설계 과정에서 AI를 활용해 구조를 검토하고 통신 프로토콜을 개선을 통해 웹서버 구축하는데 시간을 수십배 절약해 게임 로직 개발에 집중할 수 있었습니다.

    서버 통신 구조도 (Architecture)

  • Network 통신 프로토콜:
    게임서버와 웹서버는 RESTful API기반의 HTTP 비동기 통신을, 실시간 게임 플레이는 UDP 기반의 엔진 내장 네트워크(RPC, Replication)를 사용하여 최적화했습니다.
  • 데이터베이스 접근 분리:
    보안을 위해 웹 서버만 DB에 직접 접근하도록 구성했으며, 게임 서버는 웹 서버의 API를 통해 플레이어 데이터를 비동기적으로 로드·저장합니다.
  • 비동기 통신 적용:
    서버 간 통신을 비동기 방식으로 처리하여 게임 플레이 중 프레임 지연이 발생하지 않도록 했습니다.

게임 어빌리티 시스템(GAS)사용 게임 매커니즘

  • 서버 타이머 기반 어빌리티 활성화:
    자동 발동형 어빌리티의 특성을 고려해 서버에서 타이머 기반으로 능력을 활성화했습니다.
  • 역할별 Attribute Set 설계:
    캐릭터, 무기, 몬스터의 능력치 특성이 달라 각각 별도의 Attribute Set으로 분리해 관리했습니다.
  • Execution Calculation 활용한 데미지 계산:
    데미지 GameplayEffect 적용 시 캐릭터 스탯과 무기 옵션을 함께 고려하기 위해 ExecutionCalculation을 사용해 데미지를 계산했습니다.
  • GameplayEffect 기반 능력치 강화:
    무기 강화와 캐릭터 성장에 GameplayEffect를 사용해, 게임 중 능력치가 변경되도록 구성했습니다. // 이미지 추가하기 //

데이터 테이블 기반 밸런스 관리

  • 게임 밸런스 관리:
    몬스터 스텟을 DataTable과 CurveTable로 관리해 게임의 핵심 밸런스를 수정이 편리하도록 설계했습니다.
  • 랜덤 무기 강화 시스템:
    강화 옵션을 데이터로 분리해 관리하고 랜덤 선택된 옵션을 무기에 적용하도록 구현했습니다.

시간 기반 몬스터 스폰 및 난이도 조절

  • 조건 기반 이벤트 발생:

  • 엔진 내장 컴포넌트 부착 오류 개선:
    MCP 플러그인에서 제공하는 기본 컴포넌트 부착 명령어가 엔진 내장 컴포넌트에 대해 올바르게 작동하지 않는 문제를 확인하고, 탐색 경로를 올바르게 수정해 모든 엔진 내장 컴포넌트에 대해 정상적으로 부착이 이루어지도록 개선했습니다.
  • 커스텀 C++ 클래스 탐색 문제 분석 및 수정:
    MCP 플러그인에서 블루프린트 생성 시 엔진 기본 클래스만 탐색되던 문제를 확인하고 사용자 정의 클래스를 엔진에 로드된 UClass 오브젝트 풀에서 탐색해 찾을 수 있도록 플러그인의 클래스 탐색 로직을 수정했습니다.
  • 자연어 기반 블루프린트 작성 워크플로우 개선:
    클래스 내부의 함수와 변수만 찾을 수 있던 기존 로직을 수정하여 자신 외부 클래스의 변수를 가져오거나, 함수를 호출할 수 있도록 개선했습니다.
